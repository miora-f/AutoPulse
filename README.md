### AutoPulse 

AutoPulse ist ein Python-Projekt zur Überwachung von Industriemaschinen. Es analysiert Maschinentemperaturen und erkennt mögliche Überhitzungen.

### Funktionen

Überwachung mehrerer Maschinen

Automatische Statusbewertung: Normal, Warnung oder Kritisch

Berechnung der durchschnittlichen Maschinentemperatur

Anzeige einer Maschinenstatistik

### Technologien

Python

Funktionen, Bedingungen und Schleifen

Listen und Variablen

### Projektstatus

Das Projekt befindet sich in Entwicklung. Weitere Funktionen und eine grafische Benutzeroberfläche sind geplant.

### Ziel

Mit diesem Projekt möchte ich meine Python-Kenntnisse vertiefen und Programmierung mit industrieller Automatisierung verbinden.
